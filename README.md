# digidash

Widget de escritorio de DankMaterialShell que muestra un GIF de un Digimon. Se mueve y se redimensiona como PokeDash: el botón derecho arrastra el widget y la esquina inferior derecha cambia el tamaño de la caja. La grilla del escritorio, si está activa, redondea ese tamaño. G la enciende o la apaga; Z y X cambian el paso.

```bash
./install.sh
```

Hace falta DankMaterialShell. Después agregá DigiDash desde los widgets de escritorio. Dorumon, Gabumon y Terriermon vienen con el widget y se eligen en los ajustes. La escala va del 50 % al 150 %: al 150 % los tres miden la mitad del GIF de Dorumon, 100 px. El fondo puede ser transparente, el tema de DMS o vidrio.

`./install.sh uninstall` quita el plugin.
